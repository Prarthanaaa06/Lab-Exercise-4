# Lab-Exercise-4

## Aim:
To design a wireframe diagram for a Sustainable Plant Nursery mobile application (FloraCart) using Balsamiq, including 5 essential screens and navigation flow.

## Algorithm:
1. Start.
2. Open Balsamiq Mockups tool and create a new project named *FloraCart*.
3. Design the **Welcome / Splash Screen** with logo, app name (*FloraCart*), tagline, and *Get Started* button.
4. Design the **Login / Signup Screen** with input fields (Email, Password) and authentication buttons.
5. Design the **Home / Dashboard Screen** with search bar, promotional banner, category cards (*Indoor, Succulents, Pots*), and bottom navigation.
6. Design the **Product Listing Screen** with search filters, product grid cards, prices, and *Add to Cart* buttons.
7. Design the **Checkout Screen** with order summary, shipping address fields, payment options, and *Place Order* button.
8. Connect all screens sequentially using navigation arrows:
   Welcome → Login → Home → Product Listing → Checkout
9. Review layout consistency, usability, and typography.
10. Save and export the final wireframe.
11. Stop.
